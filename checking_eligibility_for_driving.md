# Checking Eligibility For Driving

## Problem
In this problem user will provide us with age input. And our program needs to tell the user if he/she is eligible for driving or not.

## Solution

I have firstly started with a variable called age. In which the program will store the user input.
Now there are two conditions in which the user will be able to driving. 1. That person should be above 18 or should be 18.
2. That person should have a driving licence.

Another variable is `q` which asks if the user have driving lincence or not, and stores the result. 

Now program will first the ask the age, and if the user is 18 or above then it goes into `if` block in which the program further asks if he/she has driving if that person have it.
It goes to if and shows that `You are eligible for drive`. In `else` it show that the user is not eligible. And in the other else it shows that `You are not eligible to drive` in case of under 18.
