# Vowel and Consonant Checker
## Problem
This code is designed to tell user if the alphabet entered by the user is either a ***vowel*** or a ***consonant***.
## Solution
In the code that I have wrote there is the option that will be showen to which is to `enter character`. And in programming world character are not just alphabets, special symbols such as: _*!*_, _*@*_ are also considered _*character*_.
So, when this program will ask the user to enter character, in case the user inputs any special character, this program will show the user that it `is neither vowel nor consonant`.
And if the user will enter any alphabet the program will tell either it is vowel or consonat. And this program is not case sensitive like either user enter samll `a` or capital `A` it will tell the user that `it is a vowel`, regardless of the case.
And samething goes for the ***consonant*** as well.
