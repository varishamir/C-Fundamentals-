# Printing Odd Numbers
## Problem

In this program we have to solve a very simple program, which is to print odd numbers on our console screen.

## Solution

In this problem I have used the `for` loop method to solve this problem. To display/print odd umbers till 25, I have to apply some formulas because withoout that the program will simply print numbers from 
1 till 25.

As we know that odd numbers are those which are not divisible by 2. So, I have simply used this formula to display only odd number.
Inside the loop I have used the condition that display the number if it is not divisible by 2, which means that the reminder of their division is not equal to zero.
Which can also be written as `i%2!=0` here i is any number from 1 to 25 and `!=` is symbol of not equals to.
