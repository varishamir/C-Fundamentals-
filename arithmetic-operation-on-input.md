# Arithmetic Operations on Input
## Problem
In this problem we are going to build a simple calculator which is going to perform different arithmetic operations on our input.
## Solution
For to build that I have used the concept of switch statement which is a multi-way control flow in c++. Firslty I have created two variables to take input which are `a` and `b`.
These will take input numbers and then the `arithmethic sign` variable will take the operator of the function that we want to perform.
The switch caase will find the operator case that user has inputed and then it will perform that specific operation.
