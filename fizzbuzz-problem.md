# FizzBuzz Problem
## Problem
In this problem I have to display two words called Fizz Buzz. Here I have to display numbers from 1 till 30.
But another part is that between the numbers between 1 till 30, that number which will be divisible by both 5 and 3 the program should display `FizzBuzz`.
And the number which is only divisible by 3 the program should display `Fizz`. And if a number is only divisible by 5 then the program should display `Buzz`.
## Solution
For to display numbers from 1 till 30 I have used `for` loop. And inside the loop I have used 3 mulitple way conditional structure in which there I have described the conditions of all three  `Fizz`, `Buzz` and `FizzBuzz` conditions.
