# Day of the Week Predictor

A simple C++ console application that takes a number input (1–7) from the user and prints the corresponding day of the week using a `switch` statement.

---

## Features

* **User Input:** Accepts an integer representing the day of the week.
* **Efficient Logic:** Uses a `switch-case` structure for fast, readable condition matching.
* **Error Handling:** Features a `default` case to handle inputs outside the 1–7 range.

---

## How It Works

The program maps numbers to days as follows:

| Input Number | Output Day |
| :---: | :--- |
| `1` | Monday |
| `2` | Tuesday |
| `3` | Wednesday |
| `4` | Thursday |
| `5` | Friday |
| `6` | Saturday |
| `7` | Sunday |
| *Any other number* | **Invalid number** |
