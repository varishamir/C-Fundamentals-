# Student Grade Evaluator (C++)

A simple and efficient console-based C++ program that determines a student's grade based on their exam marks. It utilizes conditional branching to categorize scores into standard academic performance ranges.

---

## Features
- **Dynamic Input:** Prompts the user for real-time console input.
- **Precision Ranges:** Uses logical `AND` (`&&`) operators to evaluate exact score boundaries.
- **Fail-Safe Fallback:** Automatically catches any score below 50 as a failing grade.

---

## Grading Criteria

The application maps scores to the following evaluation rules:

| Score Range | Grade Output |
| :---: | :--- |
| **80 – 100** | `Grade: A` |
| **60 – 79** | `Grade: B` |
| **50 – 59** | `Grade: C` |
| **Below 50** | `Fail` |
