# Divisibility Checker (5 and 11)

A simple C++ console application that determines whether an integer entered by the user is simultaneously divisible by both **5** and **11**.

---

## 🚀 How It Works

The program prompts the user to input a number and then evaluates it using the logical AND (`&&`) operator along with the modulus (`%`) operator. 

* **Modulus Operator (`%`):** Finds the remainder of a division. If `number % 5 == 0`, the number is perfectly divisible by 5.
* **Logical AND (`&&`):** Ensures that **both** conditions must be true for the number to be considered divisible by both 5 and 11.
