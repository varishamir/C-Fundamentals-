# Checking Eligibility For Vote

## Prolem 
This is a very simple problem that we can solve for our better understanding of c++. 

This is a very simple problem in which we have to tell the user either he/she is eligible for vote or not.
As we know that people under 18 cannot vote. And people who are 18 or above can vote. We have to keep this condition in our code.

## Solution
To solve this problem I have used first created a variable to store the input of user which is `age`. 
Then for to check either the user is eligible or not I have used _*Two-way-selection-structure*_. 

One codition is when the age input is either 18 or greater than 18, at this codition it shows that *you are eligible for vote*. 
And another condition is that if the age input by user is less than 18 then it will show that *You are not eligible for vote*.
