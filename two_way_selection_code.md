# Two way selection Code
This is program that I have wrote to show how two way selection concept in c++ works.

Two way selection is a very simple conept in which we write two different conditions in our program.
If first one becomes true then it runs the inner part and then terminates or ends the program.
And if te first condition becomes false then it goes to the second condition and executes the body of the second program.

Here in this program I have solved the problem of asking marks from user and then display if he or she is passed or not.

There is a variable that I have create which is `marks` and it will store the uer input in itself.
First condition is if condition and another is else codition. You can learn further about this from internet as well.
This if else is the standard two way selection structure in c++.
