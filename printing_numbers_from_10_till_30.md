# Printing Numbers from 10 till 30

## Problem
This is a simple C++ problem in which I have to print numbers from 10 till 30. Which means the program that I will write needs to display those numbers on the console screen, or on the user's screen.

## Solution
This problem can be solved through a classic approach which is that we can solve it by just using `cout`. `cout` is a syntax word which can be used to display anything on the console screen.

When we have to display a large amount of numbers on the console screen, we can display them by using `cout` statements. There is also another way to do that which I have used in my code.

And that method is a `for` loop. A `for` loop is a type of loop, which means that it can be used to repeat a statement for a defined number. of times. Here, I have used a `for` loop to print the numbers
