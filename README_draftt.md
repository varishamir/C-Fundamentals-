## 🛠 Getting Started

To run any of the solutions on your local machine, you will need a modern C++ compiler (such as GCC, Clang, or MSVC) or an IDE like VS Code, CLion, or Code::Blocks.

### Prerequisites

- **GCC / G++ Compiler** or any standard C++ IDE.

## 💻 How to Compile and Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. **Compile a C++ file:**
   Navigating into the folder containing the solution and run:
   ```bash
   g++ solution.cpp -o output
   ```

3. **Run the executable:**
   - **Linux / macOS:**
     ```bash
     ./output
     ```
   - **Windows:**
     ```cmd
     output.exe
     ```
